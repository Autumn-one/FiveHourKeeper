# FiveHourKeeper v1.0.0

**让每一份 AI 订阅都物尽其用** —— 主动管理 5 小时滚动窗口，不再被限额卡住。

## 这是什么

订阅了 Claude / ChatGPT 之类的 AI 服务后，通常会有一个"5 小时滚动窗口"的额度限制。
窗口什么时候刷新，直接决定你能不能用上额度。

FiveHourKeeper 会在**你指定的刷新时刻自动往前倒推 5 小时**，在那个时间点发送一次极轻量的
锚定请求，让新的窗口正好从你期望的时间开始计时 —— 该用的时候额度就绪，不用的时候不浪费。

## 主要功能

- **按目标时刻自动倒推发送**：设定"希望窗口几点刷新"，工具自动算出该在什么时候请求
- **多个模型同时托管**：OpenAI / Anthropic 兼容接口都能接，各自独立调度
- **API Key 本地加密**：使用 Windows DPAPI 加密存储，不落明文、不上传
- **三态托盘图标**：正常 / 已暂停 / 出错一目了然，鼠标悬停看下次发送倒计时
- **常驻托盘静默运行**：关闭窗口即最小化到托盘，不打扰日常使用
- **运行日志**：每次发送的时间、状态、耗时、HTTP 结果都有记录，方便排查

## 快速上手

1. 双击 `FiveHourKeeper-1.0.0-win-x64.exe` 启动
2. 进入「模型」页，添加你的接口地址、API Key 和模型名
3. 设定期望的窗口刷新时刻（建议使用整点，如 `08:00`）
4. 回到「仪表盘」确认计划 —— 工具会在发送时刻自动发出锚定请求
5. 关闭窗口会最小化到托盘（右下角 `^` 折叠区里可以找到图标），调度持续在后台运行
